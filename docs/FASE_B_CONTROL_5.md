# Fase B - Control 5

## Resultado

Se incorpora el estado operativo por inscripcion para Training Kids, manteniendo Football Academy como prealta y Gym Home como servicio futuro.

## Estados

- Borrador.
- Pendiente de completar.
- Lista para activar.
- Activa.
- Baja.

`Lista para activar` se calcula desde requisitos: datos obligatorios, documentos obligatorios firmados, grupo valido con plaza y pago inicial simulado confirmado.

## Reglas aplicadas

- Solo administracion puede activar o dar de baja.
- El pago confirmado no activa automaticamente.
- La baja local no modifica pagos ni suscripciones.
- La familia no puede asignar ni cambiar el grupo definitivo.
- La autorizacion de imagen es opcional.
- Documentos con marcas de revision quedan como pendientes de validacion y no bloquean la activacion simulada.

## Alcance tecnico

Todo sigue local, ficticio y preparado para sustituir el adaptador por Supabase en una fase posterior.
